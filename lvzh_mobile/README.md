# lvzh_mobile

#### 介绍
管理后台小程序，原生开发，大小600k内，涵盖wxcharts图表/订单/地址/审批/采购/设备列表/数据统计/提现/积分/消息通知等，包含功能模块海报/md5加密/sha1加密/签名板/腾讯位置服务/QCR证件识别/Qrcode二维码/全局消息通知/路由守卫/版本检查等

#### 软件架构
微信小程序原生开发，无任何UI框架，大小500K内，设计采购/图表/设备列表/提现/积分等功能。该小程序具有表单验证/路由拦截/类Vue的watch监听/腾讯位置JSSDK服务/图表/证件识别/md5/sha1加密解密/添加全局分享/canvas绘制海报签名板应用等功能，接下来开发换肤功能

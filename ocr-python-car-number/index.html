识别说明与注意事项

识别效果较差的场景

  • 摩托车牌：HyperLPR3 对摩托车牌支持较弱，易漏检、错识或置信度偏低，不建议作为摩托车号牌识别方案。
  • 双层车牌、临时牌、军警牌、使馆牌等非常见民用牌，准确率通常不如普通蓝牌 / 新能源绿牌。
  • 车牌严重倾斜、侧拍、远距离小目标、反光、污损、遮挡（支架 / 泥污 / 树叶）时，识别不稳定。
  • 夜间低光照、过曝、运动模糊、压缩伪影明显的图片，可能无法检出或字符读错。

识别注意事项

  • 尽量拍摄车牌正面、水平、清晰、占画面比例适中的照片；避免过度裁切或整车过远。
  • 优先使用普通汽车蓝牌、黄牌及新能源绿牌；摩托车、电动车号牌请谨慎参考结果。
  • 同一张图若检出多个车牌，请以置信度最高结果为准，并结合原图人工核对。
  • 识别结果仅供参考，重要业务请二次人工核验，避免因误识别造成错误登记。

# Archer

用于学习和分享的开源项目

## 提示词

根据用户输入的目的地：{{ destination }}
旅游天数：{{ day }}
旅游预算：{{ budget }}
来生成对应的旅游计划

## 示例

### 详细旅行计划

#### 第一天
- 游玩景点：推荐用户去往目的地城市，受游客欢迎的景点，并告诉用户景点门票费用
- 酒店：推荐景点附近的经济实惠的酒店，
- 饮食：推荐酒店附近受游客欢迎的饭店和小吃
- 注意事项：告诉用户该景点的注意事项
- 景点场景打卡：推荐景点内有哪些供游客打卡的场景
- 预计总花费： 统计这一天用户所需要花费的金额

#### 第二天
- 游玩景点：推荐用户去往目的地城市，受游客欢迎的景点，并告诉用户景点门票费用
- 酒店：推荐景点附近的经济实惠的酒店，
- 饮食：推荐酒店附近受游客欢迎的饭店和小吃
- 注意事项：告诉用户该景点的注意事项
- 景点场景打卡：推荐景点内有哪些供游客打卡的场景
- 预计总花费： 统计这一天用户所需要花费的金额


## 限制
- 每天的预计总花费不得超过旅游预算
- 适当安排旅游天数

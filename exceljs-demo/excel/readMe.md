# newExcel · ExcelJS `numFmt` 参考

本目录封装基于 **ExcelJS** 的导出能力。列样式中的 **`numFmt`** 与 Excel / WPS 中「自定义数字格式」规则一致，下表便于查阅常用写法（`cell.value` 为写入单元格的原始值）。

## 补充说明

- **四段式规则**：格式代码可按「正数；负数；零值；文本」四段书写，用英文分号 `;` 分隔。例如 `0;-0;;@` 表示：正数用第一段、负数用第二段、零值第三段留空（可理解为隐藏或走默认）、文本用第四段 `@`。
- **红色负数**：需要负数显示为红色时，可在对应段中使用 `[Red]`（注意大小写），例如：`$#,##0.00;[Red]-$#,##0.00`。
- **货币符号**：`$`、`¥` 等若紧贴数字格式，建议用双引号包起来，便于 Excel 正确解析，例如：`"¥"#,##0.00`。直接写 `¥#,##0.00` 在部分环境下可能无法按预期识别。

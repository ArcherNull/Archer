## kps4.0-app
uniapp_template项目

## 技术栈
vue3.4 + uni-app x + pinia + lodash-es

## 目录
```javascript
├─api 接口集成
├─common 公共部分
│  ├─baidu 百度开放接口方法
│  ├─constants 静态变量
│  ├─device 设备公共方法
│  ├─heart-beat 心跳公共方法
│  ├─hooks 公共hooks
│  ├─jump 跳转
│  ├─locale 国际化文件
│  ├─math 计算相关公共方法
│  ├─request 请求公共方法
│  ├─theme 主题
│  ├─utils 工具
│  └─validator 校验方法
├─components 公共组件
├─config 环境配置
├─pages 主包界面
│  └─index
├─subPagesA 副包界面A
├─sdk 外部sdk
├─static 静态资源
│  ├─images 图片
│  │  └─tabbar
│  └─styles 公共样式
├─store 状态管理
```
